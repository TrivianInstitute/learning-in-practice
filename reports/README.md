# Reviewed field reports

No real field reports have been published in v0.1. This directory will contain only accounts that have passed [submission review](../SUBMISSION_GUIDE.md) and [privacy review](../publication/privacy-and-consent.md).

A published note should be self-contained, clearly marked “single setting, self-reported,” and linked to the version of the educational resource used. Do not create placeholder reports that imply a session occurred. To practice the format, see the [fictional example](../examples/fictional-field-note.md).
